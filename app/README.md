# ibnIPS Frontend

React Native (Expo) app for indoor positioning.

## Setup

```sh
npm install
npm start
```

Requires Android 8.0+. Runs via Expo — scan the QR code with Expo Go or build an APK with EAS.

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Start Expo dev server |
| `npm run android` | Run on Android device/emulator |
| `npm test` | Run tests |
| `npm run typecheck` | TypeScript type checking |
