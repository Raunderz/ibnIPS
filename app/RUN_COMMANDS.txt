ibnIPS - Run Commands Reference
================================

Prerequisites:
- Android SDK at /opt/android-sdk
- AVD "rn_emulator" configured
- bun installed (v1.3.14)

------------------------------------------------------------
1. START ANDROID EMULATOR
------------------------------------------------------------
QT_QPA_PLATFORM=xcb emulator -avd rn_emulator -no-snapshot-load &

# Wait for boot
adb wait-for-device shell getprop sys.boot_completed

------------------------------------------------------------
2. INSTALL DEPENDENCIES
------------------------------------------------------------
cd app/
bun install

------------------------------------------------------------
3. RUN APP (recommended - builds + Metro + install + launch)
------------------------------------------------------------
cd app/
npx react-native run-android

# This single command:
#  - Builds debug APK via Gradle
#  - Installs on emulator/device
#  - Starts Metro bundler
#  - Forwards port via adb reverse
#  - Launches the app
#  - Enables hot reload / fast refresh

------------------------------------------------------------
4. IF APP CAN'T CONNECT TO METRO (red screen)
------------------------------------------------------------
# Make sure Metro is running
cd app/
bunx react-native start --reset-cache

# In another terminal, forward port and reload
adb reverse tcp:8081 tcp:8081
adb shell input keyevent 82

------------------------------------------------------------
5. RUN TESTS
------------------------------------------------------------
cd app/
bun test

# With coverage
bun run test:coverage

# Watch mode
bun run test:watch

------------------------------------------------------------
6. USEFUL ADB COMMANDS
------------------------------------------------------------
adb devices                                  # List devices
adb reverse tcp:8081 tcp:8081               # Forward Metro port
adb shell input keyevent 82                  # Reload app
adb shell am force-stop com.icpstemp         # Force stop
adb shell pm clear com.icpstemp              # Clear app data
adb uninstall com.icpstemp                   # Uninstall

------------------------------------------------------------
7. TROUBLESHOOTING
------------------------------------------------------------
# Red screen "Could not connect to development server":
adb reverse tcp:8081 tcp:8081
adb shell input keyevent 82

# Gradle immutable workspace error:
rm -rf android/.gradle && cd android && ./gradlew assembleDebug

# Metro cache issues:
bunx react-native start --reset-cache
